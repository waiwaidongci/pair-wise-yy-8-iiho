# 纸浆三班交接观察单

纸浆班三班轮换的交接观察记录：每缸每班只留一张观察单，上班签认前下个班只读，
签认后补改原始读数会连带作废后续班次并重排缸位阶段。

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-pulp-fermentation.json`。

## 文件划分

| 文件 | 职责 |
| --- | --- |
| `server.js` | 入口：HTTP 路由与页面 |
| `rules.js` | 规则：三班时隙、签认锁定、断档、补改连带作废与阶段重算（纯函数，无 IO） |
| `archive.js` | 班次档案：JSON 档案的读写与旧档兼容 |

## 交接规则

1. **三班轮换**：夜班 00:00–08:00、早班 08:00–16:00、中班 16:00–24:00（固定东八区）。
2. **每缸每班一张**：观察单含记录人、温度、气味、纤维松散度、是否换水；
   只能逐班顺延记录，不能跳班、不能提前记未来班次，中间缺班显示为断档。
3. **签认前只读**：观察单提交后为「待签认」，上班签认前下个班只能查看，
   不能追加观察单，也不能改缸位阶段；待签认单本人可修正读数。
4. **签认后补改**：已签认单的温度、换水等原始读数只能走「补改」，
   须填补改人和原因，原读数记入修订留痕；该缸其后各班有效观察单一并作废
   （留档不删、标注作废原因），由后续班次从最早断档起重排补记。
5. **缸位阶段**：完全由已签认观察单推导，不可手工修改——
   无签认单为「入缸」；最近签认单有霉/臭/腐气味为「异常观察」；
   自最近一次换水（无换水则首张签认单）起满 7 天为「可抄纸」，否则「发酵中」。

## API

- `GET /api/overview` 按缸汇总：待签认、断档、当前阶段
- `POST /api/items` 新增纸浆批次
- `POST /api/vats/:vat/sheets` 提交本班观察单
- `PATCH /api/sheets/:id` 修改待签认单读数
- `POST /api/sheets/:id/sign` 上班签认
- `POST /api/sheets/:id/amend` 签认后补改（连带作废后续班次）
